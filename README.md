# ApexEngine Single-File Loader

Use this single file in Delta by pasting the loadstring below into a script executor.

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dukkanisyerii-web/robloxesp/main/ApexEngineSingle.lua"))()
```

## What this does

- Loads a self-contained ApexEngine framework in one file
- Starts the internal plugin system
- Enables diagnostics, performance protection, resilience, analytics, and recovery modules

## Notes

If the raw GitHub URL is blocked by your executor, paste the contents of ApexEngineSingle.lua directly into the executor instead.
